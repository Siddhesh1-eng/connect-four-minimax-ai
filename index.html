View Minimax + Alpha-Beta pseudocode 
MINIMAX(state, depth, α, β, maximizing):
  if terminal(state) or depth = 0:
    return evaluation(state)

  if maximizing:
    value = −∞
    for each legal move:
      value = max(value, MINIMAX(child, depth−1, α, β, false))
      α = max(α, value)
      if α ≥ β: break  // prune branch
    return value
  else:
    value = +∞
    for each legal move:
      value = min(value, MINIMAX(child, depth−1, α, β, true))
      β = min(β, value)
      if β ≤ α: break  // prune branch
    return value

Project note: This is a heuristic depth-limited search. Terminal wins/losses take priority; non-terminal boards are scored using center control and groups of two or three discs. Move ordering checks center columns first, helping alpha-beta pruning cut more branches.
